# Signal-Date Causality Audit and Public-Data Blocker — 2026-10-17

**The public validation scripts used tomorrow's data availability to decide
today's holdings.** This audit fixes that lookahead in both validation paths.

single-symbol probes failed with upstream disconnects. No new public-market
performance result is claimed.

This bundle distinguishes synthetic engineering evidence from the public-data
failure. Neither supports investment or deployable-alpha claims. The original
proprietary paper experiment was not run or evaluated here.

## The causality issue

`_valid_forward_mask` correctly requires observations at `t` and `t+1` to build
a historical training label. Both `run_validation` and `run_full_pipeline` also
used it for portfolio eligibility and out-of-sample inference. Consequently, a
stock absent tomorrow was excluded today even though it was observed today.

The correction uses signal-date availability after the limit mask and factor
warm-up checks for selection and inference. Historical training labels and
trailing IC estimates retain their separate forward-label mask. New report
metadata records `availability_protocol`. No change to the proprietary paper
results is asserted; this finding concerns the public Python validation paths.

## Synthetic regression evidence

Two tests were run with the base script sources and failed because the stock's
weight was zero immediately before its future halt. The same tests pass with
the correction. [old-code-regressions.txt](old-code-regressions.txt) preserves
both assertion failures. Additional tests verify that MLP inference still scores
an observed pre-halt row without training on missing labels, and that trailing
IC ignores unavailable labels while scoring today's universe.

The [same-input comparison](same-input-comparison.json), generated by
[compare_signal_masks.py](compare_signal_masks.py), runs both script versions
on one fixed synthetic panel: 90 dates, 12 stocks, seed 3, with a zero-filled
halt at row 31 for stock 0. Its field-byte fingerprint is in the JSON.

| Equal-weight position | Before correction | After correction |
|---|---:|---:|
| Row 30, immediately before the halt | 0 | 1/12 |
| Row 31, the observed halt | 0 | 0 |

The desired property is that tomorrow's missing observation does not determine
today's portfolio. The same-input example changes net returns and turnover in
both directions across the simple strategies; improvement in return is not the
acceptance criterion. The generated numbers use 5 bps costs plus 2 bps slippage,
daily cadence, and 100 moving-block bootstrap samples with 20-day blocks. They
are synthetic engineering diagnostics, not predictive evidence.

## What remains unvalidated

- July 2026 A-share reports predate the mask-first/halt-safe fixes and this
  availability correction. They are preserved with explicit protocol notes.
- Their normalized input panel is unavailable in this workspace. A fresh
  provider download cannot isolate code changes from provider revisions,
  constituent changes, or environment differences. The predeclared 20-name
  diagnostic would not be the July 300-name reproduction.
- The engine still simplifies execution across halts and limits. A missing-day
  forced exit or an infeasible trade is not modeled as a real exchange fill;
  this correction removes selection lookahead, not execution risk.
- All-factor joint-mask coverage, MLP portfolio coverage, and equal evaluation
  windows need measurement on real input before interpreting comparative returns.
- Public data remains subject to adjustments, survivorship bias, ST/IPO limit
  metadata gaps, revisions, and access failures. A tradability proxy does not
  replace licensed point-in-time data.

The next data run should use the fixed scope in [plan.md](plan.md), preserve
normalized-input hashes, coverage, warnings and cost assumptions, and apply
the corrected code. The [validation dashboard](../../validation_dashboard.md)
continues to show archived evidence while that rerun is blocked by data access.
